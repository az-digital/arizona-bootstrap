List bullets: what a bigger base font size would do

Arizona Bootstrap may move its base font size from 16px to 18px. There are two ways to do that, and they affect these bullets differently. Each panel below renders the same CSS under one of those conditions. PASS means the marker art is centred on the text's line box.

The marker's vertical position is not a fixed number. Its box is one line tall (height: $line-height-base * 1em) and the art is centred inside it, so it follows the text whatever size that text ends up being. The bullets in each panel are live; the measurements beneath them were read off these same panels in Chrome.

Today

Root 16px

What ships right now. Body text is 16px, so the marker is 20px and the gap between items is 24px.

More likely

Body text 18px, root untouched

Set $font-size-base: 1.125rem and leave $font-size-root alone. Only the body type grows; 1rem stays 16px, so the marker stays 20px and the gaps stay 24px and 14px. This is the route the repo points to — the docs commit to keeping the browser's default root size, and the SCSS is mostly px, which would not scale if the root moved.

Less likely

Root 18px

Set $font-size-root: 18px, which redefines what 1rem means so every rem value in the framework grows at once — the marker becomes 22.5px and the item gap 27px.
