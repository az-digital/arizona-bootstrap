#2382: Which focus ring works best on radios?

All 3 options pass the 3:1 contrast that WCAG 2.2 SC 1.4.11 needs. This page helps pick the one that also keeps focus easy to tell apart from selection.

How to read this page

  • Each table has a row for each option and a column for each state.
  • Compare Focused, not selected with Selected. If they look alike, a keyboard user can't tell whether a radio has focus or is selected.
  • A selected radio or checkbox is filled with Arizona Red (#ab0520).
  • The rings on this page show all the time, so you don't need to press Tab.
  • Branch issue/2382 uses option 3. To try it for real, open Forms > Checks and radios, press Tab into a radio group, then use the arrow keys.

Contrast

Option Ring on white Ring on cool gray Ring on warm gray Ring next to the selected fill
1. Arizona Red 7.57:1 ✅ 6.50:1 ✅ 6.60:1 ✅ 1.00:1 (the same color)
2. Bougainvillea 5.56:1 ✅ 4.77:1 ✅ 4.85:1 ✅ 1.36:1
3. Bougainvillea at 80% 4.09:1 ✅ 3.68:1 ✅ 3.68:1 ✅ 1.85:1 on white, 1.77:1 on cool gray, 1.79:1 on warm gray

The last column is the contrast between the ring and the red fill of a selected radio. It isn't a WCAG requirement. A higher number means the ring looks more different from the selected state.

What we see

  1. Arizona Red: the ring is the same color as the selected fill. A focused radio looks like a selected radio. A selected, focused radio looks like a bigger selected radio. This option doesn't meet the APG rule.
  2. Bougainvillea: the ring is a little lighter than the selected fill, but not different enough to see at a glance.
  3. Bougainvillea at 80%: the ring is the most different from the selected fill, and it still passes 3:1 on every background. Don't go lower than 80%: the .is-invalid focus ring (Mesa) uses the same opacity, and below 80% it drops under 3:1 on cool gray.
